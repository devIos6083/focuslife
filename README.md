## 📌 트러블 슈팅

### 🔹 문제 1: Onboarding 화면에서 사용자 정보 저장이 안 되는 문제
- **원인**: `SharedPreferences`의 비동기 처리 문제로 인해 데이터가 즉시 반영되지 않음  
- **해결 방법**: `await`을 사용하여 데이터 저장이 완료된 후 화면 전환

### 🔹 문제 2: 챗봇 메시지와 사용자 메시지 간 간격이 너무 좁음
- **원인**: 연속된 메시지 간 구분이 어려움
- **해결 방법**:  
  - 같은 사용자의 연속된 메시지는 `10px` 간격  
  - 새로운 사람이 메시지를 보낼 때 `16px` 간격 추가하여 가독성 개선  

### 🔹 문제 3: 출석 체크 기록이 저장되지 않음
- **원인**: 출석 상태를 `StateProvider`로 관리했지만, 앱이 재시작되면 초기화됨  
- **해결 방법**:  
  - `SharedPreferences`를 사용하여 출석 기록을 로컬 스토리지에 저장  
  - 앱이 재시작되어도 기록이 유지되도록 수정

## 📌 학습한 내용

### **1. `flutter_riverpod`을 활용한 상태 관리**
- `StateNotifierProvider`를 사용하여 `MessagesNotifier`, `AttendanceNotifier`를 개선  
- `ConsumerWidget`과 `ConsumerStatefulWidget`을 활용하여 상태를 효율적으로 관리하는 법 학습  

### **2. `SharedPreferences`를 이용한 데이터 저장**
- `setStringList()`, `getStringList()` 등을 활용하여 출석 체크 데이터를 저장 및 불러오는 방법 학습  
- 비동기 처리 (`await SharedPreferences.getInstance()`)의 중요성을 다시 확인  

### **3. 챗봇 UI 개선**
- **`CircleAvatar`를 활용하여 챗봇 아바타 추가**  
- **대화 메시지 간격 조절 (`10px`, `16px`)로 가독성 향상**
