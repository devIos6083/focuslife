## 📌 트러블 슈팅

### 🔹 문제 1: Onboarding 화면에서 사용자 정보 저장 불가
- **원인:** SharedPreferences의 비동기 처리 문제로 데이터가 즉시 반영되지 않음  
- **해결 방법:** `await`를 사용해 데이터 저장이 완료된 후 화면 전환  
  **중요:** 비동기 처리의 완료 여부 확인은 앱 안정성에 필수!

### 🔹 문제 2: 챗봇 메시지 간 간격 부족
- **원인:** 연속된 메시지 간 구분이 어려워 가독성 저하  
- **해결 방법:**  
  - 같은 사용자의 연속 메시지 간 10px 간격 적용  
  - 다른 사용자의 메시지 사이 16px 간격 적용  
  **중요:** 메시지 간격은 사용자 경험(UX)에 직접적 영향을 미침

### 🔹 문제 3: 출석 체크 기록 저장 문제
- **원인:** 출석 상태를 StateProvider로 관리하나 앱 재시작 시 초기화됨  
- **해결 방법:**  
  - SharedPreferences를 이용해 출석 기록을 로컬 스토리지에 저장  
  - 앱 재시작 후에도 기록 유지되도록 개선  
  **중요:** 데이터 지속성은 앱 신뢰도에 핵심적 요소

## 📌 학습한 내용

### **1. flutter_riverpod을 활용한 상태 관리**
- **중요:** StateNotifierProvider를 이용해 상태를 효율적으로 관리하는 법 학습
- ConsumerWidget, ConsumerStatefulWidget 사용법 및 리팩토링 경험

### **2. SharedPreferences를 이용한 데이터 저장**
- **중요:** `setStringList()`와 `getStringList()` 등의 메서드 사용법 습득
- 비동기 처리의 이해와 `await SharedPreferences.getInstance()`의 필요성 재확인

### **3. 챗봇 UI 개선**
- **중요:** CircleAvatar 활용 및 메시지 간격 조절로 UI 가독성 향상
- 사용자 경험 개선을 위한 디자인 요소 적용

### **4. 데이터베이스 연동 및 CRUD 구현**
- SQLite를 활용한 데이터 관리 및 CRUD 연동 학습
- **중요:** 효율적인 데이터베이스 사용은 앱 성능 및 안정성에 큰 역할을 함
