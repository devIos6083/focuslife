## 트러블 슈팅

### 문제 1: Onboarding 화면에서 사용자 정보 저장이 안 되는 문제
- **원인**: `SharedPreferences`의 비동기 처리 문제로 인해 데이터가 즉시 반영되지 않음  
- **해결 방법**: `await`을 사용하여 데이터 저장이 완료된 후 화면 전환

## 학습한 내용

### 1. **Flutter에서 SharedPreferences 활용법**
- `setString()`, `getString()`을 사용해 로컬 스토리지에 사용자 정보를 저장하는 방법 학습  
- **중요한 내용**: 비동기 처리의 중요성을 다시 한번 확인
