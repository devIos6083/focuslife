## 📌 트러블 슈팅

### 🔹 문제 1: Onboarding 화면에서 사용자 정보 저장 불가
- **원인:** SharedPreferences의 비동기 처리 문제로 데이터가 즉시 반영되지 않음  
- **해결:** `await`를 사용해 저장 완료 후 화면 전환 처리

### 🔹 문제 2: 챗봇 메시지 간 간격 부족
- **원인:** 연속된 메시지 간 구분이 어려워 가독성 저하  
- **해결:** 같은 사용자 간 10px, 다른 사용자 간 16px 간격 적용하여 UX 개선

### 🔹 문제 3: 출석 체크 기록 저장 문제
- **원인:** StateProvider 사용 시 앱 재시작 시 초기화됨  
- **해결:** SharedPreferences로 로컬 데이터 저장하여 지속성 확보

## 📌 학습한 내용

### ✅ 1. Riverpod 상태 관리
- `StateNotifierProvider`를 이용한 구조적 상태 관리 방법 학습
- `ConsumerWidget`, `ConsumerStatefulWidget` 사용법 익힘

### ✅ 2. SharedPreferences 비동기 처리 이해
- `set/getStringList()` 등 메서드 사용법 학습
- `await`로 저장 완료 시점 제어하는 중요성 인식

### ✅ 3. 사용자 경험(UX)을 고려한 UI 개선
- 챗봇 메시지 레이아웃 정렬, 간격 조정
- 텍스트 스타일, 간결한 UI 구성으로 가독성 향상

### ✅ 4. 출석 캘린더 구현
- `table_calendar` 패키지 활용
- 날짜별 출석 표시, 토글 버튼을 통한 UX 고려

### ✅ 5. 오늘의 노동법 위젯 및 배너 구성
- 카드 형태의 정보 요약 위젯 구성
- 법률 정보, 계약서 가이드, 급여 계산 등 실용 기능 강조

## 📌 느낀 점

- 처음에 막막했지만, 기능 하나하나 구현하면서 구조적으로 사고하는 힘이 길러짐  
- 단순히 기능을 구현하는 것이 아니라, **사용자 입장에서 무엇이 유용한지 고민하는 경험**이 중요함  
- 상태 관리와 데이터 저장을 구조화하면서 **코드가 훨씬 명확하고 확장 가능해졌음**  
- "작은 UI 개선 하나가 전체 UX를 크게 향상시킬 수 있다"는 점을 체감함

## 📌 향후 계획

- **자연어 처리 개선:** 챗봇 응답 정확도 향상 및 RAG 응답 흐름 개선
